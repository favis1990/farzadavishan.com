# Farzad Avishan Website

This is a static website ready for Namecheap shared hosting.

## Upload to Namecheap

1. Open Namecheap cPanel.
2. Go to File Manager.
3. Open `public_html`.
4. Upload everything inside this folder:
   - `index.html`
   - `styles.css`
   - `script.js`
   - the `assets` folder
5. Make sure `index.html` is directly inside `public_html`, not inside an extra folder.

## Update the CV

Replace `assets/Farzad-Avishan-CV.pdf` with a newer PDF using the same filename.
